**Products.tsx:**
State: filter (unsent/sent/all), sort (default/sent-date/clicks), view (table/grid), selectedIds (string[] for bulk), sendTarget (product id for send modal), editTarget (product for edit modal), cleanResults (string[] | null for 404 panel), syncProgress (number | null for 0-100 progress bar).

On mount + on filter/sort/activeSubjectId change: fetch `GET /api/products?filter=...&sort=...&subjectId=...`. Show `Loader` while loading.

**Table view** (Mantine `Table`):
- Columns: checkbox, image (40x40 `Image`), name, link (truncated href), WA group, sent badge (`StatusBadge`), facebook badge, clicks, actions
- Actions per row: Send button (→ `SendModal`), Edit button (→ `EditProductModal`)
- Bulk select: select-all checkbox in header; toolbar with selected count

**Card grid view** (Mantine `SimpleGrid cols={3}`):
- Product card with image, name, StatusBadge, clicks count, Send + Edit icon buttons

**Toolbar** (above table/grid):
- Filter group: `SegmentedControl` for unsent/sent/all
- Sort group: `Select` for sort mode
- View toggle: icon buttons (table/grid)
- Sync AliExpress: `t('syncAliexpress')` icon button — calls `POST /api/products/sync` and shows progress (see Sync Progress Bar below)
- Refresh: `t('refresh')` icon button — re-fetches products
- **Shuffle**: icon button (`IconArrowsShuffle`) — calls `POST /api/products/shuffle` to randomise unsent product order; re-fetches on success. Label: `t('shuffleProducts')`.
- **Clean 404s**: icon button (`IconTrashX`) — calls `POST /api/products/clean-404s`. Shows a spinner during the request. On success, reveals the 404 Results Panel (see below). Label: `t('clean404s')`.
- **Shorten Links**: icon button (`IconLink`) — calls `POST /api/products/shorten-links`. Shows a loading state during the request. Shows success/error notification via `notifications.show()`. Label: `t('shortenLinks')`.
- **Sync Clicks**: icon button (`IconRefresh`) — calls `POST /api/products/sync-clicks`. Shows a loading state. Shows success/error notification. Label: `t('syncClicks')`.
- When selectedIds.length > 0: show bulk count chip

**404 Results Panel:**
Collapsed by default (`cleanResults === null`). When `cleanResults` is a string[], render a Mantine `Collapse` panel below the toolbar showing:
- Count: `t('clean404sResult', { count: cleanResults.length })`
- Scrollable list of the affected product URLs (each in a `Text` component, `dir="ltr"`)
- "Dismiss" button sets `cleanResults` back to null

**Sync Progress Bar:**
When `syncProgress` is not null (0–100), render a Mantine `Progress` bar below the toolbar. `syncProgress = null` hides it. The sync call can return progress via polling `GET /api/products/sync-status` every 2 seconds until `{ done: true }`, setting `syncProgress` from 0 to 100. On completion, hide progress bar and re-fetch products.

**SendModal** opens with `productId=sendTarget`, closes on cancel or after successful send (calls `POST /api/send`). After send: re-fetch products.

**EditProductModal** opens with `product=editTarget`, saves via `PATCH /api/products/:id`, closes, re-fetches.

- "Add Schedule" button at top — opens `EditScheduleModal` with `schedule=null`

**Section 2 — Broadcast Messages:**
- Fetch `GET /api/broadcasts` on mount

- "Add Broadcast" button — opens `BroadcastModal`
- Edit → `BroadcastModal` with existing broadcast data
- Delete → confirm then `DELETE /api/broadcasts/:id`
