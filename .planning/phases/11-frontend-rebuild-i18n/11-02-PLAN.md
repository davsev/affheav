**2. Routing strategy** — Tab-based routing via an `activeTab` string in App.tsx state (mirrors existing app; no react-router-dom in v1 of Phase 11). Each `<NavLink>` in the sidebar calls `setActiveTab(tabId)`. The `<main>` area renders the active page component. Document which tabs are role-gated: `users` and `feature-flags` require `role === 'admin'`.

**3. State management layers:**
- **zustand (`useAuthStore`)**: access token, user profile (sub, role, email). Persisted in memory only — no localStorage.
- **Local component state (useState)**: table filters, modal open/close, form inputs.
- **Inline fetch + useEffect**: each page fetches its own data on mount. TanStack Query deferred to a later phase.

**4. Auth flow:**
1. `App.tsx` mounts → calls `GET /api/v1/auth/refresh` (browser sends httpOnly refresh cookie automatically)
2. On success: store `accessToken` in zustand, render app
3. On 401: redirect to `/auth/login` (Express monolith Google OAuth route)
4. After login: monolith issues refresh cookie + redirects to `/` (Vite SPA root)
5. Per-request: axios request interceptor attaches `Authorization: Bearer <token>`
6. On per-request 401: axios response interceptor calls `/api/v1/auth/refresh` once (stampede guard), retries original request

**5. i18n integration:**
- `lib/i18n.ts` initialized as side effect import in `main.tsx`
- All components use `const { t } = useTranslation();` — no hardcoded strings
- `useLangSwitch()` hook calls `i18n.changeLanguage(lang)` + `setDirection(lang === 'he' ? 'rtl' : 'ltr')` + `PATCH /api/users/me/lang` atomically

**6. RTL rules:**
- `<html lang="he" dir="rtl">` set statically in index.html
- `DirectionProvider initialDirection="rtl"` wraps all Mantine components
- Every `<TextInput type="number">`, URL field, token field, and cron expression input must have `dir="ltr"` attribute
- Switching to English flips `document.documentElement.dir` to `"ltr"` via `useLangSwitch`

**7. Build + serve strategy:**
- Development: `pnpm --filter web dev` → Vite dev server on port 5173, proxies `/api` and `/auth` to `localhost:3000`
- Production: `pnpm --filter web build` → `apps/web/dist/` static assets. Express monolith serves `apps/web/dist` via `express.static`. No separate Docker service in Phase 11.

**8. Analytics charts:**
- Use `@mantine/charts` for standard line/bar charts
- Use `recharts` directly (already a transitive dep of `@mantine/charts`) for custom chart types (heatmap, polar)
- Chart.js CDN removed entirely

**9. SSE log stream:**
- `useSseLog(subjectId)` hook wraps `EventSource`
- SSE endpoint stays on monolith path (session cookie auth via dual-auth window from Phase 6 AUTH-03)
- EventSource URL: `/api/logs?subjectId=...` — proxied through Vite dev server to monolith
