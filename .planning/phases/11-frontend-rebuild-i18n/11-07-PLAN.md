**Scraper.tsx:**
Two independent forms on the same page (Mantine `Stack` layout).

Form 1 — Auto Search:
- `NumberInput dir="ltr"` for quantity (min 1, max 50)
- `Select` for niche (from `useSubjects`)
- `Select` for WA group (cascaded from selected niche — fetch groups from niche data)
- Submit button calls `POST /api/scrape/auto` with `{ qty, subjectId, waGroup }`. Show progress via `Loader` + status text.

Form 2 — Single URL Scrape:
- `TextInput dir="ltr"` for AliExpress URL
- `Select` for niche
- `Select` for WA group
- `Checkbox` for auto-send
- Submit button calls `POST /api/scrape` with `{ url, subjectId, waGroup, autoSend }`. Shows result card on success (product name + image + link). Shows error message on failure.

Both forms use `@mantine/form` (`useForm`) for state + validation. Required field validation on submit.

**AddProduct.tsx:**
Single form to manually add a product.
Fields: name (`TextInput`), affiliate link (`TextInput dir="ltr"`), image URL (`TextInput dir="ltr"`), niche select (`Select`), WA group select (cascaded).

Submit: `POST /api/products` with form data. On success: show `notifications.show()` toast and reset form. On error: show error toast.

Use `@mantine/form` for state + validation (name required, affiliate link required and valid URL format).

**AliExpressSearch.tsx:**
State: keyword, niche, waGroup, results (Product[]), loading, page.

Search form: `TextInput` for keyword, `Select` for niche, `Select` for WA group. Search button: `GET /api/aliexpress-api/search?keyword=...&subjectId=...&page=...`. Show `Loader` while fetching.

Results section:
- Summary text: `t('searchResults', { count: results.length })`
- Sort controls: `SegmentedControl` for score/rate/volume/price/stock (frontend sort only — re-sort results array in state)
- "Next Page" button: increments page and re-fetches, appends to results
- Product grid (`SimpleGrid cols={{ base: 1, sm: 2, md: 3 }}`):
  - Product card: image, name (truncated 60 chars), price (`dir="ltr"`), rating, Import button
  - Import button calls `POST /api/products` with the product data; shows success/error notification
